# GenAI AI Mentor Chatbot

A conversational AI mentor built using LangChain and Google's Gemini model. The chatbot remembers previous messages using chat history and provides guidance on GenAI, LangChain, RAG, Prompt Engineering, and AI career growth.

## Features

* Gemini LLM Integration
* Conversation Memory
* Session-based Chat History
* Career Guidance for AI Beginners
* LangChain RunnableWithMessageHistory
* Terminal-based Interface

## Tech Stack

* Python
* LangChain
* Google Gemini
* dotenv

## Installation

```bash
git clone https://github.com/yourusername/genai-ai-mentor-chatbot.git

cd genai-ai-mentor-chatbot

pip install -r requirements.txt
```

Create a `.env` file:

```env
GOOGLE_API_KEY=your_api_key_here
```

Run the project:

```bash
python app.py
```

## Example Conversation

```text
you: what is rag?

AI:
RAG (Retrieval-Augmented Generation) combines information retrieval with LLMs to generate more accurate answers.

you: how can i learn langchain?

AI:
Start with prompts, chains, memory, document loaders, and then build RAG projects.
```
